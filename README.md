# Mahmoud Wael Mahmoud — 3D CV

An interactive, single-page CV inspired by the supplied ThreeDPaper reference. The paper is built from the supplied self-contained Three.js scene; no npm install or build step is needed.

## Open

Open `index.html` in a modern browser. Internet access is used for the Inter fonts. Drag the glass CV to turn it and hover to illuminate it.

`Mahmoud_Wael_CV.docx` is the original Word CV for download or printing.

## Editing

The visible typography is painted into the paper texture in `index.html` inside `drawGlass(ctx)`. Update the matching accessible CV text near the end of the file when editing the CV. The artwork is based on the supplied 3D Paper HTML reference and retains its bundled Three.js runtime and pointer interactions.
